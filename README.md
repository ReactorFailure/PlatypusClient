# Platypus Client
A terribly made, work in progress, Fabric client-side mod. 

## Installation
1. Clone the project
```git
git clone https://github.com/ReactorFailure/PlatypusClient.git
```
2. Build the project
```
./gradlew build
```
## Dependencies
This mod requires the [Fabric API](https://modrinth.com/mod/fabric-api#download).

## Usage
> [!NOTE]
> Keybinds can be changed in Minecraft's settings

- Press `G` to open the mod's dashboard

## Features
- Night vision
- Persistent sneaking
- Persistent run
- Instant respawn
